# 高可用与容灾

## 高可用架构

- **节点级容错**：集群内任一节点故障，业务自动切换至存活节点，RTO < 30s
- **接入层高可用**：前端通过负载均衡器（如 Apusic ALB）对接集群，消除单点
- **会话复制**：开启会话复制后，节点间自动同步会话状态

## 跨机房容灾

生产关键业务建议采用同城双机房部署，两机房各部署不少于 2 节点，通过异地复制通道保持数据同步，RPO < 1min。

## 备份与恢复

| 对象 | 方式 | 建议频率 |
|------|------|---------|
| 配置文件 | 控制台导出 / 脚本打包 | 每日 |
| 应用数据 | 集群快照 | 每日 + 变更前 |
| 许可文件 | 异地存放一份副本 | 变更时 |
