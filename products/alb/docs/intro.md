# 金蝶Apusic负载均衡器简介

四层/七层一体化负载均衡与统一应用流量入口。金蝶Apusic负载均衡器（ALB）是金蝶天燕中间件产品线旗下的核心产品。

:::info 版本说明
本站同时维护 **V1.0** 与 **V2.0** 两个版本文档，请通过左侧导航栏顶部的版本切换器选择对应版本阅读。
:::

## 产品定位

负载均衡器面向企业级市场，致力于为业务系统提供稳定、高效、安全的基础能力，支持物理机、虚拟机与容器化多种部署形态，满足信创环境下全栈国产化适配要求。

## 核心特性

1. 四层/七层负载均衡与智能调度算法
2. 主动健康检查与会话保持
3. SSL 卸载与国密 HTTPS 支持
4. 可视化流量监控与弹性伸缩

## 典型应用场景

- **核心业务系统支撑**：为交易、结算等关键业务提供高可用运行底座
- **规模化集群部署**：支持跨机房多活与统一管控，满足大型企业 IT 架构要求
- **信创适配迁移**：提供从国外同类产品的平滑迁移方案与工具
