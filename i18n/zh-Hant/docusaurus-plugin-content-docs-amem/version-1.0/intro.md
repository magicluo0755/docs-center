# 金蝶Apusic記憶平臺簡介

面向 AI 應用的長期記憶存儲、檢索與生命週期管理平臺。金蝶Apusic記憶平臺（AMEM）是金蝶天燕AI 平臺產品線旗下的核心產品。

## 產品定位

記憶平臺面向企業級市場，致力於爲業務系統提供穩定、高效、安全的基礎能力，支持物理機、虛擬機與容器化多種部署形態，滿足信創環境下全棧國產化適配要求。

## 核心特性

1. 分層長期記憶存儲（事實/偏好/會話）
2. 向量 + 圖譜混合記憶檢索
3. 記憶衰減、衝突消解與自動更新
4. 多 Agent 共享記憶與隔離策略

## 典型應用場景

- **核心業務系統支撐**：爲交易、結算等關鍵業務提供高可用運行底座
- **規模化集羣部署**：支持跨機房多活與統一管控，滿足大型企業 IT 架構要求
- **信創適配遷移**：提供從國外同類產品的平滑遷移方案與工具
