# 高可用與容災

## 高可用架構

- **節點級容錯**：集羣內任一節點故障，業務自動切換至存活節點，RTO < 30s
- **接入層高可用**：前端通過負載均衡器（如 Apusic ALB）對接集羣，消除單點
- **會話複製**：開啓會話複製後，節點間自動同步會話狀態

## 跨機房容災

生產關鍵業務建議採用同城雙機房部署，兩機房各部署不少於 2 節點，通過異地複製通道保持數據同步，RPO < 1min。

## 備份與恢復

| 對象 | 方式 | 建議頻率 |
|------|------|---------|
| 配置文件 | 控制檯導出 / 腳本打包 | 每日 |
| 應用數據 | 集羣快照 | 每日 + 變更前 |
| 許可文件 | 異地存放一份副本 | 變更時 |
