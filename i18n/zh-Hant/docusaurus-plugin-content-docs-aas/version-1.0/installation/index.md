# 安裝指南

本指南覆蓋 金蝶Apusic應用服務器（AAS）生產級部署的全流程。開始安裝前，請先根據業務場景選擇部署形態。

## 部署形態選擇

| 部署形態 | 適用場景 | 參考章節 |
|---------|---------|---------|
| 單機部署 | 開發測試環境、小規模業務系統 | [單機安裝](./standalone.md) |
| 集羣部署 | 生產環境、高可用與容災要求 | [集羣安裝](./cluster-nodes.md) |

## 閱讀路徑

1. 確認 [系統要求與前置條件](./prereq.md)，準備運行環境
2. 按所選部署形態執行安裝
3. 安裝完成後，參考[使用手冊](../usage.md)完成控制檯初始化

:::warning 重要提醒
生產環境部署前，請務必完成現有環境的配置備份，並覈對安裝包 SHA-256 校驗值，確保介質完整。
:::
