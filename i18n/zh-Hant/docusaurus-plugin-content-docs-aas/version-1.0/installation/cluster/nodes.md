# 集羣組網與節點加入

多節點集羣部署時，首個節點作爲引導節點，其餘節點通過加入引導節點完成組網：

```bash
./join-cluster.sh --seed 192.168.1.10:6888 --node-ip 192.168.1.11
```

## 組網原則

- 集羣規模不少於 3 節點，並跨機架/跨機房分佈
- 節點間網絡延遲建議低於 2ms，帶寬不低於 1Gbps
- 引導節點建議部署在獨立於業務高峯的網段

## 節點狀態確認

加入完成後，通過控制檯「集羣管理」頁面確認各節點狀態均爲 Online，並檢查數據分片分佈是否均勻。
