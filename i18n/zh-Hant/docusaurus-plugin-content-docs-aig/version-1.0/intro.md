# 金蝶Apusic AI 網關簡介

多模型統一接入、Agent 工具調用管控與調用審計的 AI 原生網關。金蝶Apusic AI 網關（AIG）是金蝶天燕AI 平臺產品線旗下的核心產品。

本站同時維護 **V1.0** 與 **V2.0** 兩個版本文檔，請通過左側導航欄頂部的版本切換器選擇對應版本閱讀。
:::

## 產品定位

AI 網關面向企業級市場，致力於爲業務系統提供穩定、高效、安全的基礎能力，支持物理機、虛擬機與容器化多種部署形態，滿足信創環境下全棧國產化適配要求。

## 核心特性

1. 多模型（大模型/嵌入/多模態）統一接入
2. Agent 工具調用：服務集成、權限管控、調用審計
3. 令牌配額、限流與成本覈算
4. 內容安全與敏感信息過濾

## 典型應用場景

- **核心業務系統支撐**：爲交易、結算等關鍵業務提供高可用運行底座
- **規模化集羣部署**：支持跨機房多活與統一管控，滿足大型企業 IT 架構要求
- **信創適配遷移**：提供從國外同類產品的平滑遷移方案與工具
