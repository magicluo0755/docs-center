# 金蝶Apusic數據治理平臺簡介

數據資產目錄、元數據、數據標準與數據質量一體化治理平臺。金蝶Apusic數據治理平臺（ADGP）是金蝶天燕數據治理產品線旗下的核心產品。

## 產品定位

數據治理平臺面向企業級市場，致力於爲業務系統提供穩定、高效、安全的基礎能力，支持物理機、虛擬機與容器化多種部署形態，滿足信創環境下全棧國產化適配要求。

## 核心特性

1. 全域數據資產目錄與檢索
2. 元數據採集與血緣分析
3. 數據標準與質量規則引擎
4. 數據安全分類分級

## 典型應用場景

- **核心業務系統支撐**：爲交易、結算等關鍵業務提供高可用運行底座
- **規模化集羣部署**：支持跨機房多活與統一管控，滿足大型企業 IT 架構要求
- **信創適配遷移**：提供從國外同類產品的平滑遷移方案與工具
