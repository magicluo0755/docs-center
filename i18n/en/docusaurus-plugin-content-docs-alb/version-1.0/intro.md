# Introduction to Apusic Load Balancer (ALB)

Integrated layer-4/layer-7 load balancing and unified application traffic entry. Apusic Load Balancer (ALB) is a core product of the Apusic Middleware product line.

:::info Versioning
Both **V1.0** and **V2.0** documentation are maintained. Use the version switcher at the top of the left sidebar.
:::

## Positioning

Load Balancer delivers stable, efficient and secure infrastructure capabilities for enterprise workloads, supporting bare-metal, virtualized and containerized deployments, and full localization compliance.

## Key Features

1. Layer-4/layer-7 balancing with intelligent scheduling
2. Active health checks and session persistence
3. SSL offloading with SM-crypto HTTPS support
4. Visual traffic monitoring and elastic scaling

## Typical Use Cases

- **Mission-critical systems**: high-availability foundation for transaction and settlement workloads
- **Large-scale clusters**: multi-datacenter HA with unified management
- **Localization migration**: smooth migration from foreign counterparts
