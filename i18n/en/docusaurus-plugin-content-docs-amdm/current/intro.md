# Introduction to Apusic Master Data Management (AMDM)

Enterprise platform for unified modeling, governance and distribution of master data. Apusic Master Data Management (AMDM) is a core product of the Apusic Data Governance product line.

:::info Versioning
Both **V1.0** and **V2.0** documentation are maintained. Use the version switcher at the top of the left sidebar.
:::

## Positioning

Master Data Management delivers stable, efficient and secure infrastructure capabilities for enterprise workloads, supporting bare-metal, virtualized and containerized deployments, and full localization compliance.

## Key Features

1. Multi-domain master data model and coding management
2. Data quality auditing and cleansing
3. Cross-system code mapping and data distribution
4. Full master data lifecycle management

## Typical Use Cases

- **Mission-critical systems**: high-availability foundation for transaction and settlement workloads
- **Large-scale clusters**: multi-datacenter HA with unified management
- **Localization migration**: smooth migration from foreign counterparts
