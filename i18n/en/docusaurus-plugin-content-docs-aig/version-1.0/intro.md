# Introduction to Apusic AI Gateway (AIG)

AI-native gateway for unified model access, Agent tool-call control and audit. Apusic AI Gateway (AIG) is a core product of the Apusic AI Platform product line.

:::info Versioning
Both **V1.0** and **V2.0** documentation are maintained. Use the version switcher at the top of the left sidebar.
:::

## Positioning

AI Gateway delivers stable, efficient and secure infrastructure capabilities for enterprise workloads, supporting bare-metal, virtualized and containerized deployments, and full localization compliance.

## Key Features

1. Unified access for LLM / embedding / multimodal models
2. Agent tool calls: service integration, permission control, audit
3. Token quota, rate limiting and cost accounting
4. Content safety and sensitive-data filtering

## Typical Use Cases

- **Mission-critical systems**: high-availability foundation for transaction and settlement workloads
- **Large-scale clusters**: multi-datacenter HA with unified management
- **Localization migration**: smooth migration from foreign counterparts
