# Introduction to Apusic Distributed Message Queue (ADMQ)

High-throughput, low-latency and strongly consistent enterprise message middleware. Apusic Distributed Message Queue (ADMQ) is a core product of the Apusic Middleware product line.

:::info Versioning
Both **V1.0** and **V2.0** documentation are maintained. Use the version switcher at the top of the left sidebar.
:::

## Positioning

Distributed Message Queue delivers stable, efficient and secure infrastructure capabilities for enterprise workloads, supporting bare-metal, virtualized and containerized deployments, and full localization compliance.

## Key Features

1. Million-level TPS message throughput
2. Multi-protocol support: AMQP / MQTT / OpenWire
3. Million-level backlog with second-level replay
4. Cross-datacenter replication and disaster recovery

## Typical Use Cases

- **Mission-critical systems**: high-availability foundation for transaction and settlement workloads
- **Large-scale clusters**: multi-datacenter HA with unified management
- **Localization migration**: smooth migration from foreign counterparts
