# Introduction to Apusic Memory Platform (AMEM)

Long-term memory storage, retrieval and lifecycle management platform for AI apps. Apusic Memory Platform (AMEM) is a core product of the Apusic AI Platform product line.

:::info Versioning
Both **V1.0** and **V2.0** documentation are maintained. Use the version switcher at the top of the left sidebar.
:::

## Positioning

Memory Platform delivers stable, efficient and secure infrastructure capabilities for enterprise workloads, supporting bare-metal, virtualized and containerized deployments, and full localization compliance.

## Key Features

1. Tiered long-term memory: facts, preferences, sessions
2. Hybrid vector + graph memory retrieval
3. Memory decay, conflict resolution and auto-update
4. Shared and isolated memory across multiple Agents

## Typical Use Cases

- **Mission-critical systems**: high-availability foundation for transaction and settlement workloads
- **Large-scale clusters**: multi-datacenter HA with unified management
- **Localization migration**: smooth migration from foreign counterparts
