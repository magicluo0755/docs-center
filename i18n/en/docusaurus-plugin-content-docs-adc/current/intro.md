# Introduction to Apusic Memory Data in Cache (AMDC)

Elastic distributed cache and data acceleration platform with Redis protocol compatibility. Apusic Memory Data in Cache (AMDC) is a core product of the Apusic Middleware product line.

:::info Versioning
Both **V1.0** and **V2.0** documentation are maintained. Use the version switcher at the top of the left sidebar.
:::

## Positioning

Memory Data in Cache delivers stable, efficient and secure infrastructure capabilities for enterprise workloads, supporting bare-metal, virtualized and containerized deployments, and full localization compliance.

## Key Features

1. 100% Redis protocol and client compatibility
2. Second-level horizontal elastic scaling
3. Multi-tier caching with automatic hot-key optimization
4. Data persistence and self-healing

## Typical Use Cases

- **Mission-critical systems**: high-availability foundation for transaction and settlement workloads
- **Large-scale clusters**: multi-datacenter HA with unified management
- **Localization migration**: smooth migration from foreign counterparts
