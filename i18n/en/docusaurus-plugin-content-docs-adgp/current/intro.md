# Introduction to Apusic Data Governance Platform (ADGP)

Integrated governance platform for data assets, metadata, standards and quality. Apusic Data Governance Platform (ADGP) is a core product of the Apusic Data Governance product line.

:::info Versioning
Both **V1.0** and **V2.0** documentation are maintained. Use the version switcher at the top of the left sidebar.
:::

## Positioning

Data Governance Platform delivers stable, efficient and secure infrastructure capabilities for enterprise workloads, supporting bare-metal, virtualized and containerized deployments, and full localization compliance.

## Key Features

1. Enterprise-wide data asset catalog and search
2. Metadata harvesting and lineage analysis
3. Data standards and quality rule engine
4. Data security classification and grading

## Typical Use Cases

- **Mission-critical systems**: high-availability foundation for transaction and settlement workloads
- **Large-scale clusters**: multi-datacenter HA with unified management
- **Localization migration**: smooth migration from foreign counterparts
