# Introduction to Apusic Knowledge Management (AKM)

Integrated knowledge platform for enterprise content ingestion, RAG and app integration. Apusic Knowledge Management (AKM) is a core product of the Apusic AI Platform product line.

:::info Versioning
Both **V1.0** and **V2.0** documentation are maintained. Use the version switcher at the top of the left sidebar.
:::

## Positioning

Knowledge Management delivers stable, efficient and secure infrastructure capabilities for enterprise workloads, supporting bare-metal, virtualized and containerized deployments, and full localization compliance.

## Key Features

1. Multi-source ingestion with intelligent parsing and chunking
2. Hybrid vector + keyword retrieval (RAG)
3. Tenant isolation and fine-grained permissions
4. Open API for AI application integration

## Typical Use Cases

- **Mission-critical systems**: high-availability foundation for transaction and settlement workloads
- **Large-scale clusters**: multi-datacenter HA with unified management
- **Localization migration**: smooth migration from foreign counterparts
