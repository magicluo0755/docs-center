# Introduction to Apusic Application Server (AAS)

Next-generation application server middleware for cloud-native and mission-critical workloads. Apusic Application Server (AAS) is a core product of the Apusic Middleware product line.

:::info Versioning
Both **V1.0** and **V2.0** documentation are maintained. Use the version switcher at the top of the left sidebar.
:::

## Positioning

Application Server delivers stable, efficient and secure infrastructure capabilities for enterprise workloads, supporting bare-metal, virtualized and containerized deployments, and full localization compliance.

## Key Features

1. Full Jakarta EE 10 compliance
2. Cloud-native deployment with unified multi-cluster governance
3. AI-native application runtime support
4. SM-crypto and compliance-grade security

## Typical Use Cases

- **Mission-critical systems**: high-availability foundation for transaction and settlement workloads
- **Large-scale clusters**: multi-datacenter HA with unified management
- **Localization migration**: smooth migration from foreign counterparts
