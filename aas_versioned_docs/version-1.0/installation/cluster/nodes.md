# 集群组网与节点加入

多节点集群部署时，首个节点作为引导节点，其余节点通过加入引导节点完成组网：

```bash
./join-cluster.sh --seed 192.168.1.10:6888 --node-ip 192.168.1.11
```

## 组网原则

- 集群规模不少于 3 节点，并跨机架/跨机房分布
- 节点间网络延迟建议低于 2ms，带宽不低于 1Gbps
- 引导节点建议部署在独立于业务高峰的网段

## 节点状态确认

加入完成后，通过控制台「集群管理」页面确认各节点状态均为 Online，并检查数据分片分布是否均匀。
